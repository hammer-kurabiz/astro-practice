# 第1クール課題：AstroでコーポレートサイトのTOPページを構築する

対象期間：2026年11月〜2027年1月 ／ 配布日：2026年11月25日

## 課題の目的

デザイン見本をもとに、AstroとJavaScriptでTOPページを構築します。Astroのページ・Layout・コンポーネントの役割を理解し、配列データから表示内容を組み立て、静的サイトとしてビルドできることを目指します。

今回は、AstroでTOPページを構築できているかを確認します。デザインの細かな一致や、公開・運用の仕組みづくりは評価の対象にしません。

このフォルダは課題資料です。Astroの完成コードやスターターは含めていません。

## 配布物

| ファイル | 用途 |

| `REVIEW.md` | 提出者とレビュー担当者が使うチェックシート |

| `design/assets/` | 支給写真と出典・利用条件の案内 |

まず `design/index.html` をブラウザで開き、PC幅・スマートフォン幅の表示を確認してください。見本の表示にインストールは不要です。

## 制作するもの

架空の金属部品加工会社「東和精工株式会社」のTOPページ（`/`）を制作してください。

- ヘッダー
- メインビジュアル
- お知らせ
- 事業内容
- 私たちについて
- 加工のご相談
- フッター

文章・写真・セクションの順番は見本を使用します。PCとスマートフォンで、見本と同じ大まかな構成になるようにしてください。数px単位の余白・文字サイズ・写真のトリミングの差は問いません。

## 必須要件

1. **Astroのページとして構築する**：`src/pages/index.astro` でTOPページを作り、静的サイトとしてビルドできるようにする。
2. **Layoutとコンポーネントを使う**：`html`・`head`・`body` の共通枠をLayoutにまとめる。ヘッダー・フッター・サービス項目はAstroコンポーネントに分け、ページから読み込む。サービス項目はPropsでデータを受け取る。
3. **JavaScriptでデータを扱う**：サービス3件とお知らせ3件を、別の `.js` ファイルに配列として用意し、繰り返し描画する。サービス項目にはPropsで値を渡す。
4. **PC・スマートフォンで表示できる**：全セクションと支給写真が表示され、狭い画面でも内容が読めるようにする。PCではサービス3列、スマートフォンでは1列を基本とし、横にはみ出す・文字や画像が重なる状態を避ける。
5. **リンクと必要な操作を動かす**：ページ内リンクとメールリンクの移動先を設定する。スマートフォンのメニューを開閉できるようにする。
6. **ページの基本情報を設定する**：`lang="ja"`・title・description・viewportを設定する。h1は1つにし、会社紹介の写真にはalt属性を付ける。
7. **ビルドを通す**：`astro build` が成功する状態にする。

見本のHTMLを参考にして構いません。CSSとJavaScriptはそのまま利用・調整できます。見本のHTMLを1枚置くだけではなく、上記のLayout・コンポーネント・配列データを使ってAstroで組み立ててください。

ファイル名や分割の細かさは自由です。React等の追加UIフレームワークは不要です。

## 今回の対象外

- microCMS連携、ニュース詳細、フォーム送信、検索などの追加機能
- お知らせの自動切り替えやホバー演出など、見本の細かな動作の再現
- OGP・sitemap・構造化データなどのSEO拡張
- 自動デプロイ、ホスティング比較、納品・保守の運用設計

Web上への公開は任意です。公開していなくても、ローカルで起動・表示・ビルドを確認できれば判定できます。

## 進め方

1. Astroの最小構成でプロジェクトを作り、起動する。
2. Layoutとコンポーネントに分け、見本の内容を配置する。
3. サービス・お知らせをJavaScriptの配列から描画する。
4. CSSと必要なJavaScriptを組み込み、PC・スマートフォンで確認する。
5. ビルドを実行し、起動手順をREADMEにまとめる。

環境構築は[Astro公式セットアップガイド](https://docs.astro.build/en/install-and-setup/)を参考にしてください。提出日はMTGで決めます。
